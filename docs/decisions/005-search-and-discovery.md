# Decision 005 — Search and Discovery

**Status:** Accepted
**Date:** 2026-08-08

## Goal

The article discovery system is a core part of Lemma.

The system must remain intuitive when the archive contains approximately 100+ articles.

## Search

Search should eventually consider:

* title
* description
* author
* topics
* tags
* article content where practical

## Filters

Users should be able to filter by:

* topic
* tag
* format
* author
* year
* peer-review status

## Sorting

The initial sorting options are:

* relevance
* newest
* oldest
* alphabetical

## UX Principle

Do not expose every filtering mechanism simultaneously in an overwhelming interface.

Desktop can use a filter sidebar.

Mobile can use a filter drawer or sheet.

Search should be the fastest path to finding a specific article.

Browsing by topic should be the fastest path to discovering unfamiliar mathematics.
