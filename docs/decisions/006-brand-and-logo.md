# Decision 006 — Brand and Logo

**Status:** Accepted
**Date:** 2026-08-08

## Brand Concept

Lemma uses a leather/parchment-inspired colour palette.

The visual identity should communicate:

* scholarship
* mathematics
* craftsmanship
* warmth
* permanence

## Palette

```text
#2B1509 — Dark Chocolate
#4A2410 — Brown
#8C4A1E — Saddle
#C9A876 — Tan
#B8894A — Brass
#F5EDE0 — Parchment
```

## Light Mode

Parchment is the dominant background colour.

Dark chocolate is the primary text colour.

## Dark Mode

Dark mode should reinterpret the same palette rather than introduce an unrelated colour identity.

## Logo

The square Lemma logo will be supplied as a reference image.

Location:

`/public/brand/lemma-logo-reference.png`

The reference image is not necessarily the final web asset.

The logo should be recreated as a scalable native web graphic, preferably SVG, if the visual complexity allows.

The recreation should preserve the original logo's geometry, proportions, typography, and identity.

## Homepage

The homepage will begin with:

* Lemma name
* motto
* square logo
* atmospheric mathematical background

The publication content will emerge through scrolling.

## Navigation

The square logo will appear prominently in the navigation drawer.
