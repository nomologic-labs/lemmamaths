Decision 003 — Content Model

Status: Accepted
Date: 2026-08-08

Article

An article can contain:

title
author
date
updated date
description
topics
tags
format
reading time
peer-review status
content
references
media assets
Topics

Lemma currently has nine top-level topics:

Algebra
Calculus
Linear Algebra
Topology
Arithmetic
Statistics & Probability
Number Theory
Computer Science
Numerical Analysis
Tags

Tags represent specific concepts.

Examples:

Fourier transform
prime numbers
matrices
probability
optics
algorithms

Articles can have multiple topics and tags.

Formats

The initial formats are:

Article
Investigation
Problem
Essay
Report
Reasoning

Topics provide broad navigation.

Tags provide detailed discovery.

Formats provide context about the type of work.

This separation is intended to prevent the archive from becoming an unstructured collection of hundreds of unrelated tags.
