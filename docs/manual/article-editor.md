# Article editor

## Status

**Not implemented in V0.1.**

The Author Dashboard at `/dashboard` is a labelled placeholder that describes future drafting, submission, and refereeing panels. It does not create or edit articles.

## Intended direction (not built)

From `rules/30-content-and-editor.mdc` and the content model in `src/data/types.ts`:

- Browser editor with editor / split / preview modes
- Insertion of text, headings, equations, figures, code, mathematical statements
- Autosave for drafts
- Output as the same `ArticleBlock[]` tree the reader already renders

Do not document UI controls, APIs, or save endpoints here until they exist.
